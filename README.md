  <h1>💸 Refund - Sistema de Solicitação de Reembolso</h1>

  <span class="badge badge-yellow">Status: Em Desenvolvimento</span>


  <h2>📌 Visão Geral</h2>
  <p>O <strong>Refund</strong> é um sistema web simples e funcional para gerenciamento de solicitações de reembolso. Ideal para empresas que desejam otimizar o processo de reembolso de despesas, proporcionando uma interface amigável e eficiente para colaboradores e gestores.</p>

  <h2>🚀 Funcionalidades</h2>
  <ul>
    <li>Formulário intuitivo para envio de solicitações de reembolso.</li>
    <li>Validação de campos obrigatórios.</li>
    <li>Listagem de solicitações pendentes, aprovadas e recusadas.</li>
    <li>Interface responsiva e adaptável a diferentes dispositivos.</li>
  </ul>

  <h2>🖥️ Tecnologias Utilizadas</h2>
  <ul>
    <li>HTML5</li>
    <li>CSS3</li>
    <li>JavaScript</li>
  </ul>
